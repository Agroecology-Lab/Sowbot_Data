    About this run

    Source. The unmodified sowbot_avoid agents from Agroecology-Lab/Sowbot (caatinga-dev, commit 5a59a20), run on a synthetic field map in the repo's map format: 8 rows of 15 m, 1.2 m apart, a stop every 3 m.

    Setup. Random scenario, 3 robots, seed 0, 10% random frame loss, 1 m clearance, 0.5 m/s, straight-line motion between stops. Frames: 8 bytes each, 21 bytes on air.

    Model limits. One collision domain where every robot hears every other. A lost frame is lost for all receivers at once. No range, no dynamics, no tracking error.

    Result. All 3 robots finished in 207.3 s with 50 frames sent, 3 lost (random loss, no collisions) and 2 side-steps. The simulator recorded a closest approach of 1.34 m between moving robots, above the 1 m clearance. Routes end on field nodes, and a finished robot keeps blocking its last stop. The readout above samples every 0.25 s, so it can read slightly higher.

    Status. Simulation only. Not run on hardware. Not a safety function.
